# demo-page — "נובה טרייל"

A single self-contained HTML page, built to answer one request: "I just want
to see a page that works and a link I can open where the page works." No real
product behind it — all content (name, stats, quotes) is invented on purpose,
per the founder's own instruction.

- Pure HTML/CSS/JS, no build step, no dependencies. Opens directly in a
  browser or from any static host.
- One interactive element (a button that picks a random fake trail) so the
  page is visibly alive, not a static screenshot.
